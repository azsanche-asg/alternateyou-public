# AlternateYou

Choose a decision you might have made differently. Give that branch its own timeline and talk with an imagined version of yourself about the tradeoffs it brings into view.

[AlternateYou at Burrito’s Labs](https://burritoslabs.com/catalogue/alternate-you/)

## Technology

Swift, SwiftUI, Core Data and a TypeScript generation service.

## Architecture

SwiftUI and Core Data keep timelines, messages and memory summaries on the iPhone. The app can use a rule-based local engine or a separate AI service for conversations.

## Development status

The native development build includes local timelines and reflective conversations. Each simulated perspective belongs to the timeline it came from.
